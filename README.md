# Gerador de Capas — versão 2.10.12

Versão limpa baseada na 2.10.11, com auditoria das alterações desta entrega.

## Correções e melhorias

- Ordem de camadas unificada entre imagens e textos.
- “Trazer à frente” e “Enviar para trás” agora atuam sobre todos os elementos.
- A ordem exibida no painel de camadas corresponde à ordem real de renderização.
- A seleção por clique respeita a camada visualmente superior.
- Ctrl + rolagem aplica zoom tomando o ponteiro como centro.
- Barra de espaços ativa a ferramenta mão para navegar pela pré-visualização.
- Exportação PSD em camadas permanece descartada.
- Guias técnicas e exportação PSD tradicional não foram alteradas.
- Cache atualizado para `gerador-capas-v2.10.12`.

## Atalhos

- `Ctrl + rolagem`: zoom no ponto do ponteiro.
- `Espaço + arrastar`: mover a pré-visualização.
- `Alt` durante movimento: ignorar o snap.
- `Ctrl + Z`: desfazer.
